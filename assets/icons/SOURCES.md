# Application logos

`googlechrome.svg`, `discord.svg`, `telegram.svg`, `spotify.svg`, `steam.svg`,
`openai.svg`, `neovim.svg`, `vim.svg`, `cmake.svg`, `htop.svg`, and `counterstrike.svg`
are unmodified monochrome SVGs from [Simple Icons 11.15.0](https://github.com/simple-icons/simple-icons/tree/11.15.0/icons).
The collection uses CC0 1.0; its license is included in `SIMPLE-ICONS-LICENSE.md`.
Brand names and marks remain the property of their respective owners.

`kitty.svg`, `foot.svg`, `thunar.svg`, `prism.svg`, `openrgb.svg`, and `java.svg` are compact geometric
adaptations drawn for Luch, following the installed applications' recognizable
cat-and-terminal, footprint prompt and cursor, file cabinet, faceted cube,
colour-wheel, and steaming-cup silhouettes.

`minecraft.svg` is a compact pixel Creeper face drawn for this launcher. It uses
transparent space and the current theme colour, without a tile or Prism frame.

Applications without a bundled vector use their own installed desktop icon,
preferring the matching symbolic variant. The renderer converts that original
artwork to a theme-coloured alpha mask; it never substitutes a category icon.
